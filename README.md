# 🍰 Receitas do Kinho

Um pequeno livro de receitas feito em HTML puro. A página inicial funciona como um menu com foto e link de cada receita, e cada receita tem a sua própria página com ingredientes e modo de preparo.

## 📖 Receitas

| Receita | Ranking do Kinho | Página |
| --- | --- | --- |
| Bolo de Cenoura | 🥇 O melhor bolo do Brasil | [`pages/boloCenoura.html`](pages/boloCenoura.html) |
| Bolo de Milho | 🥈 2º melhor bolo do Brasil | [`pages/boloMilho.html`](pages/boloMilho.html) |
| Bolo de Chocolate com calda de chocolate | 🥉 3º melhor bolo do Brasil | [`pages/boloChocolate.html`](pages/boloChocolate.html) |

## Estrutura do projeto

```
Receitas-do-Kinho/
├── index.html          # Menu principal com as receitas
├── pages/
│   ├── boloCenoura.html
│   ├── boloChocolate.html
│   └── boloMilho.html
└── img/                # Fotos dos bolos
```

## Como visualizar

1. Baixe ou clone o repositório:
   ```bash
   git clone https://github.com/Dev-Erick-Rodrigo/Receitas-do-Kinho.git
   ```
2. Abra o arquivo `index.html` no navegador (dois cliques já resolvem, não precisa de servidor).
3. Clique em uma receita para ver os ingredientes e o modo de preparo. Em cada página existe o link **Voltar ao Menu**.

## Tecnologias

- HTML5 com tags semânticas (`header`, `main`, `nav`, `footer`)
- Listas ordenadas e não ordenadas para ingredientes e passos
- Navegação entre páginas com links relativos
